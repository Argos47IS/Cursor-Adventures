# Telegram Channel Stats Collector

Автоматический сбор статистики Telegram-каналов в области IT, AI, технологий и вайбкодинга.

## Возможности

- Сбор количества подписчиков с 20–30 каналов за один запуск
- Фильтрация каналов по размеру (5 000 – 40 000 подписчиков)
- Расчёт прироста подписчиков за последние 24 часа
- Ежедневный запуск в 16:00 по МСК (планировщик или cron)
- Сохранение отчётов в CSV (UTF-8, открывается в Excel/Google Sheets)
- Хранение истории в SQLite для отслеживания динамики

## Быстрый старт

### 1. Получите Telegram API ключи

1. Перейдите на https://my.telegram.org/apps
2. Войдите по номеру телефона
3. Создайте приложение — получите **API ID** и **API Hash**

### 2. Установите зависимости

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройте `.env`

```bash
cp .env.example .env
```

Откройте `.env` и заполните:

```
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=abcdef1234567890abcdef1234567890
TELEGRAM_PHONE=+79001234567
```

### 4. Первый запуск (авторизация)

```bash
python collector.py
```

При первом запуске Telegram пришлёт код подтверждения — введите его в терминал.
После этого создастся файл сессии `tg_session.session` и повторная авторизация не потребуется.

### 5. Настройте автоматический запуск

**Вариант А: cron (рекомендуется для сервера)**

```bash
bash setup_cron.sh
```

Скрипт добавит задачу в crontab: ежедневно в 13:00 UTC (= 16:00 МСК).

**Вариант Б: встроенный планировщик**

```bash
python scheduler.py
```

Планировщик работает в фоне и запускает сбор каждый день в 16:00 МСК.


## Формат отчёта (CSV)

| Канал | Username | Подписчики | Прирост за 24ч |
|-------|----------|------------|----------------|
| AI News | @ai_newz | 15 200 | +320 |
| Python Scripts | @python_scripts | 8 400 | +45 |

- При первом запуске прирост будет «нет данных» — он появится со второго дня
- CSV сохраняется в папку `reports/` с датой в имени файла

## Настройка списка каналов

Отредактируйте `channels.json` — добавьте или удалите юзернеймы:

```json
{
  "channels": [
    "@ai_newz",
    "@your_new_channel",
    ...
  ]
}
```

Каналы вне диапазона 5 000–40 000 подписчиков автоматически пропускаются (но данные всё равно сохраняются в базу для истории).

## Диапазон подписчиков

По умолчанию: 5 000 – 40 000. Можно изменить в `collector.py`:

```python
MIN_SUBSCRIBERS = 5_000
MAX_SUBSCRIBERS = 40_000
```

## Решение проблем

| Проблема | Решение |
|----------|---------|
| `FloodWaitError` | Скрипт автоматически ждёт; при частых ошибках увеличьте `asyncio.sleep()` |
| Канал не найден | Проверьте юзернейм в `channels.json` |
| Нет прироста | Прирост появится после второго запуска (нужны данные за 2 дня) |
| Ошибка авторизации | Удалите `tg_session.session` и запустите заново |
